Keeping this safe

  • The app is not on the public internet. It answers only on the server's own network and over Tailscale, so there is no login page for anyone else to find.
  • The database file is encrypted at rest, so a copied file is useless without the key. The key lives in the server's environment, not in the database.
  • Failed sign-ins are counted and the account locks itself for a while after too many — that stops someone on your Tailscale network guessing the password.
  • Every sign-in, price change and cancelled invoice is written to the audit log.
