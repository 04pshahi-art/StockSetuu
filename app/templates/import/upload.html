Getting the file out of Tally

This app does not assume any particular Tally layout. Export whatever your Tally actually produces — the columns it contains are read from the file itself and shown back to you to map. Different Tally versions and different companies name these columns differently, and guessing would quietly corrupt your catalogue.

  1. In Tally: Gateway of Tally → Display More Reports → Inventory Books → Stock Summary.
  2. Press Alt + F12 (Configure) and turn on the columns you want to carry over — typically quantity, rate and value. If you keep HSN and GST rate on the stock item, include those too.
  3. Press Alt + E (Export), choose CSV (or Excel / .xlsx), and note where it saves the file.
  4. Copy that file to wherever you are using this app, and upload it above.

Anything Tally cannot give you — sale price, low-stock level, warranty months — can be left unmapped and filled in later on the product screens. It is fine to import the same file twice; the second run updates instead of duplicating, matched on SKU.

What the import will and will not do

  • Matches on SKU. A row whose SKU already exists updates that product. A new SKU creates one. Nothing is ever duplicated.
  • Only overwrites what you map. Columns you leave unmapped are not touched, so an import that has no sale price will not wipe the prices you have already set.
  • Opening stock goes through the ledger, exactly like a purchase, so every unit on hand can still be explained later.
  • It never deletes. A product missing from the file is left alone — this is an import, not a sync.
  • Serial numbers are not imported. They arrive with purchases, where they can be tied to a bill, a date and a warranty.
  • Nothing is written until you confirm the dry run, and if any row fails mid-write the whole import is rolled back.
